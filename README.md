# 立会い帳

退去の立会い中に、部屋の状態と、その場で言われたことをスマホへ残すための最小版です。法律相談でも、敷金が戻る保証でもありません。

画面の記録は無料です。印刷用の記録、記録ファイルの保存、請求書が来たあとの確認リストは買い切り500円です。カード決済は Stripe Checkout で、支払い確認が取れたブラウザだけ機能を開きます。秘密鍵は環境変数 `STRIPE_SECRET_KEY` に置きます。

## いまの状態

実装済み

- 説明ページ、全部屋の記録、まとめ、料金の説明、購入前の壁
- 記録はブラウザ内だけ。本文はサーバーへ送らない
- 金額をその場で了承しない案内（無料）
- 印刷、記録ファイル、残りの確認リスト（購入後のページを開いたブラウザだけ）
- 操作名だけの計測。公開先の受け口は置いたが、まだ公開していない
- オフラインは、一度オンラインで開いたあとに限る（サービスワーカー）

テスト済み

- 記録の作成、文字数の切り詰め、壊れた保存データの読み飛ばし、手数料の計算（`node test/model.test.js`）
- 画面操作はローカルで確認する。公開サイトでの購入完了は未確認

未対応

- 販売者情報（特定商取引法の氏名、所在地、電話、メール、返品）
- 一般公開
- 独自ドメイン
- 公開先での計測の保存（KVの作成が必要）
- 写真の取り込み（意図的にやっていない）
- 負担額の自動計算（意図的にやっていない）

## ローカルで開く

`tachiai-cho/site` で次を実行する。

```powershell
python -m http.server 8765
```

ブラウザで `http://127.0.0.1:8765/` を開く。ファイルを直接開くと、一部のブラウザでスクリプトが動きません。

購入後の画面の確認は、ローカル限定で `http://127.0.0.1:8765/app.html?unlock=1` を開く。公開したサイトではこの指定は効きません。

ロジックのテスト:

```powershell
node test/model.test.js
```

`tachiai-cho` ディレクトリで実行する。

## 価格と損益

販売価格は500円の買い切り。月額ではない。

BOOTHのダウンロード商品のサービス利用料は、公式ヘルプでは「商品価格 × 5.6% + 45円」、小数点以下切り上げ。2026年10月24日にヘルプを確認した。

- 1,480円 × 5.6% + 45円 = 128円
- 差引 1,352円
- 銀行振込で受け取るときの振込手数料は、この計算に入れていない。金額は未確認

固定費は、Cloudflare Pagesの無料枠に収まるあいだは0円。静的ファイルの配信は無料、FunctionsはWorkersの無料枠（1日10万リクエスト）に含まれる。2026年10月24日にCloudflareの料金ページを確認した。独自ドメインは買っていない。

損益分岐は、固定費0円なら有料1件で販売手数料を超える。これは売上の予測ではない。振込手数料と作業時間は別。

作業時間の目安は、公開手続きに2時間、その後30日間は週1時間の確認。個別の書類作成はしない。メールが来た場合に返すかどうかは、そのときに決める。

## 公開するとき

公開、決済の契約、広告、第三者への送信は、実施前に内容と金額を確認する。

1. `site/legal.html` の空欄に、販売業者、所在地、電話番号、メール、支払方法、返品の方針を書く。
2. 決済を選ぶ。BOOTHで売る場合、商品ファイルは `sales/checklist.html` にする。2026年7月8日から、中身がなく外部サイトへ誘導するだけの商品は禁止になっている。`site/js/config.js` の `paymentUrl` には、その商品ページのURLを書く。サイト内の「購入後」ページは、このブラウザで印刷機能を開く動作確認用で、代金の証明にはならない。
3. Cloudflareの無料アカウントで、Pagesのプロジェクトを作る。公開するフォルダは `tachiai-cho/site` だけにする。`test` と `sales` は公開しない。
4. 集計を残すなら、同じアカウントでWorkers KVの名前空間を作り、PagesのFunctionsに `METRICS` という名前で結ぶ。`ADMIN_TOKEN` に長いランダム文字列を入れる。結ぶまで、回数は各ブラウザの中だけに残る。
5. 公開後に `metrics.html` を開き、トークンで合計を見る。記録の本文は出てこない。

`thanks.html` は公開サイトでは開けません。代金なしでは機能は開きません。機能が開くのは、Stripeが支払い済みと返した確認ページだけです。確認ページのアドレスを知っている人は、そのブラウザでも開けます。コピー防止ではありません。

## 直す場所

- 文言と料金の数字: `site/index.html`、`site/js/config.js`
- 部屋と箇所: `site/js/model.js` の `CATALOG`
- 確認リスト: 同じファイルの `BILL_CHECKS`。`free: true` の項目は、払う前でも表示する
- 見た目: `site/css/app.css`

部屋を増やしたら `node test/model.test.js` を再実行する。
